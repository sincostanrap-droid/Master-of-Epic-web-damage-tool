# v17: 装備カタログ 数値条件フィルタ

装備カタログの「効果」フィルタに、数値条件を追加する。

例:

- 攻撃ディレイ `-2 以下`
- 攻撃力 `4 以上`
- 命中 `10 以上`

## 仕様

- 「効果」で対象ステータスを選ぶ。
- 「数値条件」で `以上 / 以下 / 超 / 未満 / 等しい` を選ぶ。
- 「効果値」に閾値を入力する。
- 値が未入力の場合は従来通り「その効果がある装備」の絞り込みとして動く。
- 同じ追加ステータスが複数行ある装備は合計値で判定する。
  - 例: 攻撃力 +1.5 が2行なら、攻撃力 +3 として判定。

## 注意

計算処理・装備登録処理には触れない。カタログ表示の絞り込みだけを追加する。
