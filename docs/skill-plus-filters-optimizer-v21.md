# v21: スキル強化フィルタ / スキル強化最大化

## 目的

装備Buff由来の `skillPlus`（例: `skillPlus|戦闘技術|20`）を、ステータス・必要スキル・成功率へ加算せず、検索/最適化の条件・評価軸として扱う。

## 仕様

- スキル強化はキャラクターの基礎スキル値へ加算しない。
- 武器/装備の必要スキル判定へ使わない。
- スキル成功率へ使わない。
- ダメージ式へ直接加算しない。
- 装備カタログでは最大4条件ANDで絞り込み可能。
- 最適化計算βでは「スキル強化最大」を優先目標/同点時目標に選べる。
- 対象スキル未指定の場合は、取得できる `skillPlus` の合計を最大化する。
- 対象スキルを指定した場合は、そのスキルの強化値を最大化する。

## 既知の注意

スキル強化最大化は、既存の最適化探索候補の範囲内で並び替え/条件判定を行う。最大値を厳密に見たい場合は、装備候補の確認数や全通り試す上限を大きめにする。
