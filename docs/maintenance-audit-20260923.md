## 監査数値の読み方

```
generated=1162 manual=668 runtimeStats=80
remaining=0
reviewStatus={"display-only":422,"unverified":15,"implemented":171}
unverifiedReview={"finalized":12,"pending":3}
semanticDisplayDuplicates.remaining=0
```

remaining=0は全効果の数値計算対応を意味しない。表示のみ・未検証項目も含む。
pending=3はコビトカバフォーム、カブトムシフォーム、ちびヒーローギャンブラーフォーム。
ユーザー指定で追加対応対象外とした。監査を通すために検証済みへ偽装せず、元の未検証データと説明表示を維持する。
