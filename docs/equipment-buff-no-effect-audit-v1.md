## 分類方針

- 実装可能: 効果対象と数値が明記され、現行フィールドへ安全に接続できる。
- 表示のみ: 数値は明記されているが、現行の物理計算・最適化の対象外。
- 未検証: 数値不明、条件不明、推定値、または複数ソース間で意味が確定しない。

## 未検証として継続

generated 候補1,162件のうち、今回の作業前時点で manual 未登録かつ正規化済みの
数値効果を持たない候補は876件あった。これらは一括自動実装せず、効果対象・
数値・競合条件を1件ずつ確認してから後続バッチで manual へ昇格する。

今回確認した範囲では、キック/牙攻撃力、反射、追撃、確率発動、落下速度、
水中速度などを通常攻撃力・通常移動速度・物理与ダメージへ読み替えると誤計算に
なるため、明示的に表示のみ、または未検証として残す。
