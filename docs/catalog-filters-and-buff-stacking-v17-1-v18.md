# v17.1 + v18 combined patch

## 含まれる修正

### v17.1: 装備カタログ 複数数値フィルタ

装備カタログに「追加ステータス数値フィルタ（最大4条件・すべて満たす）」を追加する。

例:

- 攻撃力 `4` 以上
- 攻撃ディレイ `-1` 以下
- 命中 `1` 以上

複数条件は AND 条件として判定する。同じ追加ステータスが複数行ある装備は合計値で判定する。

### v18: 装備Buff重複対策 + 見せびらかし表示修正

- 装備Buff展開時に、同一 `equipBuffTechnicId` / 同一 `equipBuffName` は最新1件だけを計算へ渡す。
- `equipBuffTechnicId` が無い旧TSVや手入力行は Buff 名で同一判定する。
- 見せびらかしページの装備欄で `攻撃力+8 / 攻撃力 +8` のように、攻撃力・魔力・速度が二重表示される問題を修正する。

## 適用順

この同梱版では `v17.1 → v18` の順番で適用する。

## 注意

v17.1 は UI と検索条件の拡張、v18 は装備Buff展開と表示の修正。どちらも `src/main.js` に触るため、個別パッチを別々に適用せず、この同梱版を1回だけ適用するのが安全。
