# v18: 装備Buffの同一テクニック最新1件化と見せびらかし表示修正

## 目的

装備カタログから投入した装備で、同一装備Buffが複数部位に付いている場合でも、MoE側の挙動に合わせて同一テクニックID / 同一Buff名は最新1件だけを計算へ展開する。

旧TSVや手入力行では `equipBuffTechnicId` が無いことがあるため、その場合は `equipBuffName` を正規化した名前で同一判定する。

## 修正内容

- `expandEquipmentBuffState()` の前段で、装備由来Buffを `resolveEquipmentBuffRowsForSameTechnic()` に通す。
- 判定キーは `equipBuffTechnicId` 優先、無ければ `equipBuffName`。
- 同一キーが複数ある場合は、装備一覧上で後ろにある行を最新として採用する。
- 見せびらかしページの装備欄で `attack / magic / speed` を表示した後、`extraStatsSummary()` 側でも同じ値を再表示していたため、装備欄ではその3項目を除外する。

## 確認例

- `クロエ なりきりブーツ` と `クロエ なりきりレッグガード` の両方が `クラスカード・アーチャー` の場合、魔力→攻撃力変換は1件分だけになる。
- `闘魂` が複数部位に付いている場合も、装備Buffとしては1件分だけになる。
- 見せびらかしの装備欄で `攻撃力+8 / 攻撃力 +8` のような二重表示が出ない。

## 注意

「最新」は現時点では装備一覧の表示順で後ろにある行として扱う。実ゲーム内の装備順・点灯順を完全に再現する専用UIは今後の課題。
