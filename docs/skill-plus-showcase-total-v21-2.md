# v21.2: 見せびらかしにスキル強化合計を表示

## 目的

見せびらかしページに、現在の構成全体で得られる `skillPlus` の合計値を表示する。

例:

```txt
スキル強化合計: 戦闘技術強化 +20 / 物まね強化 +20 / 筋力強化 +20
```

## v21.1 からの変更

v21.1 は各装備行に `戦闘技術強化 +20` のように表示していたが、意図と違うため、v21.2 では装備ごとの表示ではなく、見せびらかしページ上部の合計表示へ変更する。

v21.1 が既に適用済みの場合、このパッチは装備行への `showcaseSkillPlusSummaryParts(row)` の挿入だけを取り外す。

## 仕様

- skillPlus はステータス、必要スキル、成功率、ダメージ式には加算しない。
- 表示専用の合計値として扱う。
- 同一装備Buff最新1件化が入っている場合は `resolveEquipmentBuffRowsForSameTechnic()` を使ってから集計する。
- 見せびらかしのテキスト欄にも合計行を入れるため、コピー文面にも含まれる。

## 確認例

- ミリタリーアーツ系装備を1つ入れる → `戦闘技術強化 +20`
- サイボーグ系装備を1つ入れる → `物まね強化 +20`
- 両方入れる → `戦闘技術強化 +20 / 物まね強化 +20`
- 同一Buffが複数ある場合、v18 の最新1件化後の値で合計される。
