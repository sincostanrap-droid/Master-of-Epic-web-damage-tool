# v23: 装備カタログ描画軽量化

## 目的

iframe分離でUI破損が出たため、構造変更を避けて安全寄りに軽量化します。

## 内容

- 装備カタログ検索/フィルタ描画を debounce します。
- カタログ表示件数の初期値を 80 件寄りにします。
- `さらに表示` ボタンで段階的に表示件数を増やせるようにします。
- 追加ステータス数値と skillPlus 解析結果を WeakMap でキャッシュします。

## 触らないもの

- ダメージ計算式
- 装備登録データ構造
- Buff競合処理
- 最適化計算ロジック
- カタログ/見せびらかし/アタックDPSのタブ構造

## 確認

1. カタログを開いて、初期表示件数が小さめになる。
2. 検索欄に連続入力しても固まりにくい。
3. `さらに表示` で表示件数を増やせる。
4. 装備追加結果や計算結果が変わらない。
