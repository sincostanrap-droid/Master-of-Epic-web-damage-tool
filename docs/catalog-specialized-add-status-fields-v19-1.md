# v19.1: 専門戦闘追加ステータスの正規フィールド化

## 目的

Buff効果ではない公式DB/Wiki由来の追加ステータスは、装備本体の追加ステータスとして保持・表示する。

## 追加フィールド

- `extraKickAttack`: キック攻撃力補正
- `extraKickHit`: キック命中率補正
- `extraFangAttack`: 牙攻撃補正（既存）
- `extraFangHit`: 牙命中率補正

## 修正内容

- キック攻撃力補正を通常攻撃力へ混ぜない。
- キック命中率補正を通常命中へ混ぜない。
- 牙命中率補正を通常命中へ混ぜない。
- 牙攻撃補正は従来通り牙攻撃補正として保持する。
- これらを表示用 custom ではなく、装備本体追加ステータスとして保存・TSV出力・数値フィルタ対象にする。

## 確認例

- 闘魂マスク: 攻撃力 +3 / 命中 +3 / キック攻撃力補正 +5 / キック命中率補正 +5
- ストライプ スーツ: 攻撃力 +3 / 攻撃ディレイ -3 / キック攻撃力補正 +10 / キック命中率補正 +10
- ウエスト バット リボン: 最大HP +8 / 牙攻撃補正 +3 / 牙命中率補正 +3

既に誤った値で登録済みの装備は、パッチ後にカタログから再投入してください。
